ABOUT THE PROJECT

A complete personal finance management application.

ExpensePro is a portfolio-ready application built with Python Flask, SQLite, Jinja templates, CSS and JavaScript.

Technology stack

Frontend

HTML5, CSS3, JavaScript and Jinja templates

Backend

Python 3 and Flask

Database

SQLite with relational tables

Security

Session authentication and password hashing

Core modules

  • User registration and secure login
  • Dashboard and financial summary
  • Income and expense CRUD
  • Search and filters
  • Monthly budget management
  • Reports and chart
  • CSV export
  • Profile and password management
